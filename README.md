# Hospital Readmission Prediction

This project predicts whether a patient will be readmitted within 30 days using **Logistic Regression with L2 regularization**. Patient diagnosis, vitals, and previous visits are used as features. Data is preprocessed, split into training/testing sets, and evaluated using **ROC-AUC**. False negatives are important because missed high-risk patients may not receive timely follow-up, while false positives can increase unnecessary healthcare resources.
